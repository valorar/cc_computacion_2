Pregunta guía
Si mañana te pidieran programar, de memoria y sin apuntes, un programa que ordena tres números, ¿qué escribirías primero y qué partes se te resistirían?
01 / REPASO

Lo que ya sabes programar

En Ciencias de la Computación I ya escribiste programas con tipos, condicionales, bucles, funciones y listas. Este tema no repite esa teoría: la reactiva con un foco nuevo: que el programa funcione siempre, también con entradas vacías o fuera de rango.

Cada variable guarda un dato de un tipo —int (2027), float (3.5), str ("cc2"), bool (True/False)— y las operaciones dependen de él. El primer fallo real suele estar en la conversión, porque input() devuelve siempre texto:

anio = int(input("¿En qué año naciste? "))   # input da texto: conviértelo
print(f"En 2027 cumplirás {2027 - anio} años.")
# int("") -> ValueError   float("7.5") -> 7.5   (decimales con punto)
Idea claveinput() entrega texto: conviértelo con int() o float() antes de operar.
02 / FLUJO

Decidir y repetir con precisión

Python evalúa las ramas de un if en orden: gana la primera condición verdadera. El orden de los elif cambia el resultado, así que prueba siempre los bordes: un 4,9 no es lo mismo que un 5,0.

def palabra_para(nota):
    """Traduce una nota de 0 a 10 a calificación textual."""
    if nota < 5:
        return "suspenso"
    if nota < 7:
        return "aprobado"
    if nota < 9:
        return "notable"
    return "sobresaliente"

# Pruebas: 4.9->suspenso · 5.0->aprobado · 7.0->notable
#          9.0->sobresaliente · -1->sobresaliente (¡sin validar!)

Para repetir, for recorre una colección y while repite hasta que ocurra algo. El límite de range(a, b) nunca se incluye:

total = 0
for numero in range(1, 101):       # recorre 1..100; el 101 no entra
    total += numero
print(total)                       # 5050, la suma de Gauss

for nombre in ["Ada", "Grace", "Alan"]:
    print(f"Hola, {nombre}")
Idea claveUn for sobre una colección vacía no ejecuta su cuerpo; un while necesita que algo avance hacia la parada.
03 / PIEZAS

Funciones: piezas con nombre que se reutilizan

Una función empaqueta lógica con un nombre y unos parámetros: la pruebas por separado y la reutilizas. Conviene verbalizar una diferencia: imprimir no es devolver. Una función sin return devuelve None, el valor que representa «aquí no hay dato».

def edad_en_2027(nacimiento):
    """Años que cumplirá en 2027; None si el dato falta o no es plausible."""
    if nacimiento is None or nacimiento < 1900:
        return None
    return 2027 - nacimiento

# Pruebas: 2010->17 · 2026->1 · None->None · 1500->None

None se comprueba con is None. Distinguir el cero (dato real) de la ausencia de dato (None) te acompañará todo el curso.

04 / LISTAS

Listas y cadenas: colecciones ordenadas

Cadenas y listas son secuencias: se indexan desde 0, admiten índices negativos y rebanadas. Difieren en algo clave: las cadenas son inmutables (todo crea copias: upper(), split()) y las listas son mutables (cambias elementos o añades con append()).

notas = [7, 8, 5, 9]
notas.append(6)
print(len(notas), sum(notas))      # 5 35

def media(numeros):
    """Media aritmética; None si la lista está vacía."""
    if not numeros:
        return None
    return sum(numeros) / len(numeros)

# Pruebas: [7, 8, 5, 9, 6]->7.0 · [10]->10.0 · []->None

frase = "computación"
print(frase[:4], frase[-3:], len(frase))   # comp ión 11
# frase[0] = "C"                           # TypeError: str inmutable
05 / ENTORNO

Ejecutar programas: del archivo .py a cualquier entorno

Python se usa de dos formas: el intérprete interactivo (símbolo >>>), que responde a cada orden y sirve para probar ideas, y el script, un archivo de texto con extensión .py que ejecuta todas sus líneas de una vez. En el aula usas IDLE, Thonny o Visual Studio Code; desde el terminal, python3 archivo.py; y entornos web como Replit o Google Colab corren Python en el navegador: mismo lenguaje, distinto lugar.

# temperaturas.py: convierte grados Celsius a Fahrenheit
celsius = float(input("Temperatura en °C: "))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius} °C son {fahrenheit} °F")

Si la entrada no es un número, Python detiene el programa y muestra un traceback con archivo, línea y tipo de error (ValueError: could not convert string to float: 'veinticinco'). Aprender a leer ese rastro es la primera habilidad del tema 15.

06 / SALIDA

Lo esencial

  1. input() devuelve texto: conviértelo con int() o float() antes de operar.
  2. if/elif deciden en orden y range(a, b) excluye el límite superior: prueba los bordes.
  3. Las funciones dan nombre y reutilizan lógica; sin return devuelven None, el «sin dato».
  4. Listas mutables y cadenas inmutables; ambas se indexan desde 0 y admiten rebanadas.
  5. Un script .py se ejecuta con python3 y corre igual en el escritorio que en un entorno web.
