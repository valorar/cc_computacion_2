Almacenar y recuperar: ficheros y estructuras de datos

Todo lo que un programa calcula vive en la memoria y desaparece al cerrarlo. Este tema enseña a guardar datos en ficheros y a elegir la estructura adecuada para organizarlos.

  • 6–7 sesiones
  • Prácticas de la evaluación
  • 1 evaluación Moodle
  • Trabajo en el aula

Al terminar podrás:

  • leer y escribir ficheros de texto controlando la codificación y los saltos de línea;
  • guardar y recuperar datos tabulares con CSV y estructuras anidadas con JSON;
  • elegir entre lista, tupla, conjunto y diccionario según lo que necesites hacer;
  • construir un programa que conserva su estado entre una ejecución y la siguiente.

Pregunta guía
Cuando cierras un programa, todo lo que había en su memoria desaparece. ¿Dónde guardarías la lista de libros prestados de la biblioteca del aula para recuperarla mañana?
01 / TEXTO

Ficheros de texto: leer y escribir líneas

Un fichero es memoria de largo plazo: sobrevive a la ejecución. La forma segura de usarlo es with open(...), que garantiza el cierre aunque ocurra un error. Al abrir indicas un modo: "r" (leer), "w" (crear o vaciar) o "a" (añadir al final), y conviene declarar encoding="utf-8".

with open("bitacora.txt", "a", encoding="utf-8") as f:
    f.write("2027-05-04: el guardado funciona\n")   # \n separa líneas

with open("bitacora.txt", encoding="utf-8") as f:
    for linea in f:                  # recorre el fichero línea a línea
        limpia = linea.rstrip("\n")  # cada línea trae su salto final
        if limpia.strip():           # descarta las líneas en blanco
            print(limpia)

Recorrer con un for evita cargar el fichero entero en memoria. Si el archivo no existe, Python lanza FileNotFoundError: en la sección 5 verás cómo tratarlo.

Idea clavewith open() abre y cierra por ti; "w" sobrescribe y "a" añade; y cada línea leída trae su \n, así que límpiala antes de usarla.
02 / TABLAS

Datos tabulares: el formato CSV

Cuando la información tiene forma de tabla, el CSV la guarda como texto separado; en España el separador habitual es el ;, porque la coma ya se usa en los decimales. El módulo csv se ocupa de los casos molestos: campos con comillas, saltos internos o celdas vacías.

import csv

with open("notas.csv", newline="", encoding="utf-8") as f:
    lector = csv.DictReader(f, delimiter=";")  # la 1.ª fila son las cabeceras
    for fila in lector:
        print(fila["nombre"], "->", fila["nota"])

Cada fila es un diccionario con las cabeceras como claves; con fila.get("nota", "") obtienes un valor por defecto si la celda falta, pues una columna inexistente lanza KeyError. Un fichero vacío o sin cabecera no produce filas. Para escribir, csv.writer convierte listas en filas.

03 / JSON

Datos estructurados: JSON

CSV aplana los datos en una tabla; JSON guarda estructuras anidadas —listas de diccionarios con listas dentro— y es el formato estándar de intercambio entre programas. Python lo traduce casi directamente: objeto a diccionario, matriz a lista, null a None.

import json

datos = {"equipo": "Los Mutables", "puntos": [3, 5, 2], "activo": True}

with open("equipo.json", "w", encoding="utf-8") as f:
    json.dump(datos, f, ensure_ascii=False, indent=2)   # indent: legible

with open("equipo.json", encoding="utf-8") as f:
    recuperado = json.load(f)

print(recuperado["puntos"])     # [3, 5, 2]

ensure_ascii=False conserva ñ y á sin escapes e indent=2 deja el archivo legible. Si el contenido no es JSON válido, json.load lanza JSONDecodeError: decide qué hacer con un dato dañado.

04 / MEMORIA

Colecciones: elegir la estructura adecuada

En memoria tienes cuatro colecciones principales. La lista mantiene orden y admite duplicados. La tupla es su versión inmutable, ideal para parejas que no cambian. El conjunto elimina duplicados y no guarda orden. El diccionario asocia claves a valores y busca por clave al instante.

nombres = ["ana", "bea", "ana", "car"]   # lista con duplicados
unicos = set(nombres)                    # conjunto: sin repetidos
print(len(nombres), len(unicos))         # 4 3

telefonos = {"ana": 600111222, "bea": 600333444}
print(telefonos.get("car"))              # None: esa clave no existe
telefonos["car"] = 600555666
print(sorted(telefonos))                 # ['ana', 'bea', 'car']

dict.get(clave) devuelve None si la clave no existe, mientras que telefonos["car"] antes de añadirla lanzaría KeyError: elige entre «sin dato» o error.

Idea claveLista si importa el orden, tupla si no debe cambiar, conjunto si sobran duplicados, diccionario si buscas por clave.
05 / ESTADO

Programas con estado: guardar y recuperar

Un programa «con estado» recuerda entre ejecuciones: contadores, agendas, marcadores. La receta es cargar al empezar, actualizar en memoria y guardar al cambiar. Y cargar debe ser tolerante: el fichero puede no existir la primera vez, estar vacío o contener basura.

import json

ARCHIVO = "contador.json"

def cargar():
    """Contador guardado; 0 si el archivo no existe o no es válido."""
    try:
        with open(ARCHIVO, encoding="utf-8") as f:
            valor = json.load(f)
        return valor if isinstance(valor, int) else 0
    except (FileNotFoundError, json.JSONDecodeError):
        return 0

# Pruebas de cargar(): sin archivo->0 · "7"->7 · vacío->0 · "[1, 2]"->0

El fichero se crea en la carpeta de trabajo del programa, no necesariamente junto al script. Este patrón de carga tolerante es el que usarás en el proyecto del tema 16.

06 / SALIDA

Lo esencial

  1. with open() gestiona apertura y cierre; escribe encoding="utf-8" y recorre líneas con for.
  2. "w" sobrescribe y "a" añade; cada línea leída trae su \n: límpiala con rstrip("\n").
  3. CSV guarda tablas separadas por ; en España; DictReader usa la primera fila como cabecera.
  4. JSON guarda estructuras anidadas (null pasa a None); json.dump guarda y json.load recupera.
  5. Elige la colección según el caso y haz que cargar() tolere ficheros inexistentes o dañados.
